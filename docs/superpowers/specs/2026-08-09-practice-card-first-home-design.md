# 练习首页卡片优先设计

## 目标

练习首页移除左上方的“练习”导航标题和卡片上方的“随机”标签，让题目卡成为进入页面后的第一视觉焦点。

## 范围

- 仅调整有当前题目时的练习首页布局。
- 移除 `PracticeView` 的“练习”导航标题。
- 移除 `PracticeFeedView` 卡片上方包含“随机”的标题行。
- 让题目卡向上延展并使用释放出的垂直空间，同时保留现有水平安全间距。
- 保持滑动提示、“跳过”和“开始回答”按钮、撤销操作及答题导航行为不变。
- 保持题库为空、未选择主题和筛选结果为空等空状态不变。

## 视觉层级

页面从上到下依次为题目卡、滑动提示和主要操作按钮。题目卡紧接顶部安全区域出现，不额外添加替代标题、装饰或工具栏；卡片内部主题、题型和难度信息继续承担上下文说明。

## 可访问性

- 题目卡、滑动提示和操作按钮沿用现有辅助功能标识。
- 删除的“练习”和“随机”不再出现在练习首页的辅助功能树中。
- 不改变按钮点击区域和语义标签。

## 验收标准

1. 有题目时，练习首页顶部不显示“练习”和“随机”。
2. 题目卡明显上移并增高，仍完整显示卡片、提示和底部操作按钮。
3. 跳过、开始回答、滑动和撤销行为不变。
4. 各类空状态保持现有布局与文案。
5. 相关测试通过，并在指定 iPhone 17 Pro Max 模拟器上完成视觉检查；不安装到真机。
